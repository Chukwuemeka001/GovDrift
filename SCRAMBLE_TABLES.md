# ARM D (SCRAMBLED) — FROZEN LEDGER CONTENTS
**Frozen at pre-registration. Arm D receives the SAME banner and the SAME ledger
structure, entry count, and approximate entry length as arm B, but with entry CONTENTS
swapped to the plausible-wrong values below. If successor behavior is content-driven
(the mechanism claim), arm B must beat arm D; arm D enforcing these wrong rules is
itself a measured outcome, reported.**

The scrambled entries are identical across projects except for the domain-noun
substitutions in the table at the bottom.
